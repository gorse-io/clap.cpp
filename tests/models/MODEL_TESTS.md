# Unified architecture model contracts

`model_tests.py` is the common stdlib-only entry point for model/CLI contracts.
Following llama.cpp's architecture test and per-model tokenizer registration
pattern, CTest selects an architecture and passes its generated fixture to one
runner. This is not a dispatcher to the former standalone scripts: command
execution, exit/diagnostic checks, JSON vector/frame validation, waveform
writing and string-metadata GGUF rewriting live in `model_contract.py`.
Architecture modules supply fixtures, mutations and expected results.

```sh
python tests/models/model_tests.py --list
python tests/models/model_contract_test.py
python tests/models/model_tests.py --arch clap2 --suite invalid \
    --build "$BUILD" --fixture "$BUILD/clap2-smoke"
python tests/models/model_tests.py --arch mert --suite invalid --cli "$BUILD/clap"
python tests/models/model_tests.py --arch mert2 --suite cli \
    --cli "$BUILD/clap" --fixture "$BUILD/mert2-fixture" --case full-song-frames
```

`--case` selects case names by substring. Unknown architectures, unsupported
suites, missing required arguments and filters selecting no cases fail rather
than silently skipping coverage. `--list` requires neither native binaries nor
fixtures nor optional Python packages. Failures identify architecture, suite,
case, native argv, exit status and captured stdout/stderr. Preparation failures
identify architecture/suite and the underlying error.

## Coverage retained from the standalone runners

| Architecture/suite | Fixture source | Contract cases |
| --- | --- | --- |
| `clap/cli` | optional `parity.py` | All text cases, exact dimensions and max absolute error **< 3e-5**; all three invalid argument combinations; 16 kHz resampled versus 48 kHz native silence, including the explicit 32-mel frontend rejection contract. |
| `clap2/invalid` | stdlib `clap2_fixture.py` | Converter schema/tensor shapes and metadata discovery; complete analytical F32/F16 native public API smoke; all 12 malformed config/processor/tokenizer cases rejected by both converter and native loader; missing and wrong-shape QKV tensors and original diagnostic alternatives. |
| `clamp3/cli` | optional `clamp3_parity.py` | 48 kHz mono waveform and dimension 6; all three obsolete options rejected with diagnostics; bad-architecture model rejection. |
| `clamp3/invalid` | optional `clamp3_parity.py` | Negative pad token, negative epsilon and causal decoder mutations, preserving tensor infos/payload and exact expected diagnostics. |
| `mert/invalid` | stdlib metadata fixture | All 31 native metadata mutations, requiring a **positive** rejection exit and original diagnostic substring; all 44 converter metadata/processor/revision rejections; all seven invalid positional-weight representations; post/pre-norm identity, exact config and source revision preservation. |
| `mert2/cli` | optional `mert2_parity.py` | Same full-song case and IEEE F32 waveform; pooled dimension and max error **<= fixture tolerance**; frame count, dimension, full value count and max error **<= fixture tolerance**; each native invocation retains its 120-second timeout. |

CTest names, parity-option gates, dependencies, fixture setup and existing
60/120/180/30-second CTest deadlines remain unchanged. `model_contract_framework`
adds dependency-free selection/diagnostic, tolerance, GGUF-rewrite and adapter
inventory regressions. Native public C API calls remain explicit in the
unchanged C++ oracle executables; this framework does not wrap that API.

## Extending coverage

Register an `Architecture` in `model_architectures/__init__.py`, explicitly
listing its suites and required fixture/build directory. Its `cli(context)` or
`invalid(context)` generator yields named `Command` records. Use `Vector` and
`Frames` for shared output checks, `Diagnostic` when alternative messages have
different case-sensitivity, and `Compare` for paired native outputs. Reserve
`Check` for genuinely architecture-specific conversion checks. Keep command
execution in the shared runner, not in adapters. Register each fixture through
`clap_add_model_contract` and attach its existing CTest properties explicitly.

The string-only GGUF helper intentionally supports the generated test fixtures,
not arbitrary GGUF metadata types. No production loader/frontend code changes
are needed to add an architecture contract.

Official numerical oracles, tokenizer internals, FFT/RoPE tests, bundled-model
pipeline tests and MuQ conversion/quantization checks remain separate because
they have distinct algorithms, dependencies or contracts. The unified runner
does not replace or weaken them. Optional fixtures are still generated by their
existing parity tests; CTest `DEPENDS` retains ordering semantics, not automatic
fixture generation when a user selects only an optional CLI test.
